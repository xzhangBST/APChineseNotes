# Read the article到中国人家做客

古老的中国被称为“礼仪之邦”，很多传统礼仪在今天的日常生活中也依然随处可见。中国人喜欢请客，常常邀请亲朋好友到家里吃饭。如果了解一些做客的基本礼仪，能帮助你在赴宴时举止得体。

去中国人家做客时，衣着要整洁得体，带些小礼品，以表示对主人的尊重。

客人要等主人邀请后才能入座落座。入座后，千万不能急于动筷子，要等主人开始示意开动，客人才能用餐。

夹菜时一次不要夹太多，也不能伸长胳膊去夹远处的菜，还要记得一定要用公筷。千万要避免弄开玩笑，开口嚼食吃饭，或把骨头吐在桌子上，这些是不礼貌的行为。

如果桌上有一壶茶水在你的旁边，你要记得帮着为你周围的客人倒茶。如果有人给你倒茶，你应当用手指轻轻敲击桌面，以示感谢之意。

要结束用餐前要说明，告诉主人要回家了，也是应有的礼节。

# Read the article年夜饭

一年中，中国人家庭最重要的一顿家宴要数年夜饭了。

大年夜也叫除夕，是中国农历年的最后一天。人们辞旧迎新，工作忙、离家再远，都要赶回家，和家人一起吃年夜饭。人们甚至会为家里不回来的亲人留个位子，放一副碗筷，以示团聚。可见，年夜饭是中国人最重视的团圆饭。

年夜饭当然少不了一桌美味丰盛的年菜。一家人围坐在一起，享受满桌的佳肴和快乐的气氛，是中国人家最愉悦的时刻。对于年菜，中国人非常重视寓意。每一道菜，不但要美味，而且吉祥。由于中国国土辽阔，南北方的年菜也不尽相同。北方人过年要吃饺子，而南方人传统上会蒸年糕。吃鱼时，中国人会讲究“年年有余”的寓意；做一道“白斩鸡”，表示人们希望来年中生活更吉祥顺利。所以很多来自南方和北方的朋友都合在一起了。现代人还新创出一些吉祥的年菜，例如“五福临门”、“百团圆圆”、“员工添开”。

过年是中国文化中很重要的一部分，而年夜饭作为过年的主要传统，总是源远流长。
